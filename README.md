# Carro pendulo invertido — LQR anti-oscilacion (experimental v2)

Version basada en el `src/main.cpp` de `Texto pegado(4).txt` y en los
encabezados del ZIP autoencendido previo. Aporta modulacion del PWM bajo zona
muerta, escala de aceleracion y un trim opcional del cero.

La salida no garantiza un equilibrio estable; cargar con los motores
sin potencia y hacer el primer intento con corte fisico a mano.

Consultar `INSTRUCCIONES_MEJORAS.md`.
